# Archived

This repo held 3D-printable hardware files (servo and bellows/gears parts)
for a physical Voight-Kampff machine build.

The Voight-Kampff project has been consolidated into a single repo focused
on software emulation (Raspberry Pi + web viewer):

**[polerix/voigt-kampff-empathy-test](https://github.com/polerix/voigt-kampff-empathy-test)**

The STL files that were here have been removed from git rather than moved
into that repo — they're 3D hardware design files, out of scope for a
software/web-service project, and are kept locally by the project owner
instead. See that repo's `docs/design/aesthetic.md` for the project's
current design notes.

This repo is no longer maintained.
